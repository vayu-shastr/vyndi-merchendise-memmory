# PQ1-04 — Physical-Print Validation

Physical validation must use controlled print settings and measured results.

## Required chain

`requested → exported mesh → slicer interpretation → measured print → deviation → PASS/FAIL`

## Minimum measurements

- X reference dimension;
- Y reference dimension;
- Z / overall relief;
- wall thickness;
- base thickness;
- minimum ridge width;
- minimum valley/channel width;
- GPX track width/depth;
- coastline/shore transition;
- minimum text stroke/readability;
- building footprint;
- building minimum height;
- bridge/rail/path features where present;
- multicolour/material boundary accuracy where applicable;
- dovetail/key fit and seam gap for tiled output.

## Record process variables

- printer/model;
- firmware;
- slicer/version;
- nozzle/resolution;
- material/resin/powder;
- layer height;
- walls/perimeters;
- infill;
- orientation;
- temperatures/exposure;
- calibration state;
- measurement instrument/resolution.

Photos are supporting evidence; dimensional measurements are the governing evidence.
