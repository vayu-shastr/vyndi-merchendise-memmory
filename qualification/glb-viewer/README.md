# PQ1-06 — GLB Viewer / AR

This gate is **non-blocking for manufacturing qualification**.

Qualification target:
- load governed GLB output;
- rotate/pan/zoom;
- preserve terrain/material-region rendering;
- show route/GPX presentation correctly;
- verify mobile behavior;
- verify AR path only on supported devices/browsers;
- record browser/device/version limitations.

Do not hold a manufacturing release solely because PQ1-06 remains open.
