# VYNDI Terrain + Merchandise

Standalone extraction of **My Road — My Glory merchandise** and the **Terrain Medal Studio** from `vayu-shastr/vyndi-ride-stories`.

Included: merchandise catalogue/configuration/cart preparation, Terrain Medal Studio, GPX, DEM/GeoTIFF, vector mapping, geographic outlines, STL/OBJ/GLB/3MF production exports, fabrication/tiling, authenticity, terrain/map/event/geography APIs, tests and qualification evidence.

Excluded: VYBES community backend, authentication, profiles, riders, posts, journals, admin, and Community Durable Objects.

Community links remain external to the existing VYNDI Ride Stories community.
