# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to **info@vayushastr.com**.

Include:

- affected URL or component
- clear reproduction steps
- observed and expected behavior
- security impact
- screenshots, request/response samples or logs when useful

Do not post an unpatched vulnerability publicly before the team has had a reasonable opportunity to investigate and remediate it.

## In scope

- My Road — My Glory / VYNDI Ride Stories public website
- Terrain Medal Studio
- same-origin Worker APIs
- generated export/provenance flows owned by this repository

## Out of scope / prohibited testing

Do not perform destructive testing, denial-of-service/load attacks, credential attacks, social engineering, physical attacks, or testing against unrelated third-party services.
